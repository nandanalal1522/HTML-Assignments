My journey into web development

Written by Nandana

November 22, 2026

Why I started learning HTML

I started learning web development because I wanted to understand how websites are created and how they work. As someone interested in the IT industry, I wanted to explore new technologies and develop practical skills that would help me grow as a developer.

My Learning Experience

My learning journey started with HTML, where I learned how to structure a webpage using different tags and elements. Initially, understanding the purpose of each tag was challenging, but practising by building a webpage helped me understand the concepts better. I realized that learning by doing is one of the best ways to improve my skills.

What's Next in My Journey

After learning the basics of HTML, I plan to explore CSS to improve the appearance of my webpages. Later, I want to learn JavaScript to make websites interactive. My goal is to keep practising, build small projects, and gradually become a confident web developer.

"The secret of getting ahead is getting started."

- Mark Twain
